# Dataset

This folder contains both the original survey dataset and the cleaned dataset used for analysis.

---

## Files

| File | Description |
|------|-------------|
| **Investment Preference Dataset.xlsx** | Original dataset containing investor survey responses. |
| **CLEANED_DATA.xlsx** | Cleaned dataset used for analysis and dashboard development. Missing values were handled, data types were standardized, and the dataset was transformed for reporting. |

---

# Dataset Overview

The dataset contains survey responses from individual investors and captures information about their demographics, investment preferences, financial goals, and investment behavior.

Each row represents one respondent.

### Key Data Categories

- Demographic Information
  - Gender
  - Age

- Investment Preferences
  - Mutual Funds
  - Equity Market
  - Debentures
  - Government Bonds
  - Fixed Deposits
  - Public Provident Fund (PPF)
  - Gold

- Investment Behavior
  - Investment Duration
  - Expected Returns
  - Investment Decision Factors
  - Reasons for Investing in Mutual Funds
  - Financial Goals
  - Savings Objectives

---

# Data Source

The dataset was provided as part of the WealthBridge Advisors investment preference analysis project.
