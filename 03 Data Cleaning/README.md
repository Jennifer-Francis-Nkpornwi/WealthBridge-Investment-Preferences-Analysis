
# Data Cleaning

This folder documents the data preparation process carried out before analysis and dashboard development.

High-quality insights depend on high-quality data. Before any visualizations or KPIs were created, the dataset was inspected, cleaned, standardized, and transformed to ensure consistency and reliability.

## Folder Contents

| File | Description |
|------|-------------|
| **Data Cleaning.md** | Detailed documentation of the data cleaning and transformation process. |

## Cleaning Objectives

The data cleaning process focused on:

- Improving data quality
- Handling missing values
- Standardizing categorical values
- Removing duplicate records
- Creating analysis-ready fields
- Preparing the dataset for Power BI reporting

The cleaned dataset produced from this process was used throughout the analysis and dashboard development.
